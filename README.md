# Gemini Flash Text Summarization Example

This Python script demonstrates how to use the Gemini 3.5 Flash model to summarize long text. It takes an input string and returns a concise summary, showcasing the model's text processing capabilities.

## Language

`python`

## How to Run

1. Set your GOOGLE_API_KEY environment variable.
2. Run the script: python gemini_flash_summarizer.py
